# 憋七 · Bie7

一个基于 C++ 实现的扑克牌游戏「憋七」。建议在全屏窗口下游玩。

## 游戏简介

憋七是一种多人扑克牌游戏。玩家需要根据当前牌局选择合适的牌进行出牌或扣牌，在尽可能打出自己手牌的同时，也需要考虑限制其他玩家的出牌空间。

本项目使用 C++ 实现，支持单人模式和多人模式，并提供两种牌面展示方式。

## 游戏模式

### 单人模式

玩家与 AI 对战。

AI 会根据当前牌局选择出牌，并加入一定的随机性，使不同对局不会完全采用相同的策略。

### 多人模式

支持多名玩家轮流使用同一设备进行游戏。

玩家切换时会进入过渡界面，下一位玩家确认后才能查看自己的手牌，以避免其他玩家看到手牌。

## 主要功能

- 单人模式
- 多人模式
- AI 自动出牌
- AI 随机策略
- 两种牌面展示方式
- `C` 键切换牌面展示方式
- 多人模式下每位玩家独立保存展示方式
- 显示上一轮其他玩家的出牌记录
- 多人模式按照实际出牌顺序显示历史出牌
- 自动计算玩家扣分
- 本局结束后根据扣分判定胜者
- 支持 `-1` 随时退出游戏
- 非法输入处理
- 玩家切换时的隐私保护

## 操作说明

| 输入 | 功能 |
| --- | --- |
| `C` / `c` | 切换牌面展示方式 |
| `-1` | 退出游戏 |
| `Enter` | 在玩家切换界面确认并进入下一位玩家回合 |

具体出牌操作根据游戏界面的提示进行。

## 游戏结束

多人模式下，只有当**所有玩家手中的牌全部出完**后，本局才结束。

游戏会统计每位玩家本局的扣分：

> **扣分最少的玩家获胜。**

## 编译运行

确保系统已经安装 C++ 编译器，例如 `g++`。

在项目目录下执行：

```bash
g++ bie7.cpp drawCard.cpp -o bie7
```
Windows 下可以生成：

g++ bie7.cpp drawCard.cpp -o bie7.exe

然后运行：
```bash
./bie7
```

项目结构
```bash
bie7/
├── bie7.cpp       # 游戏主要逻辑
├── drawCard.cpp   # 牌面绘制相关实现
├── drawCard.h     # 牌面绘制相关声明
└── README.md      # 项目说明
```
